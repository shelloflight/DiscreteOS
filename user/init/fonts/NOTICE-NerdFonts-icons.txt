iosevka-term-nf-mono.ttf
========================

A subset of "IosevkaTermNerdFontMono-Regular.ttf" from Nerd Fonts 3.5.1
(https://github.com/ryanoasis/nerd-fonts), which is Iosevka Term 34.8.0
(https://github.com/be5invis/Iosevka) patched with the Nerd Fonts icon sets.

The subset keeps Latin, Greek, Cyrillic, punctuation, box drawing, block elements, arrows,
mathematical symbols and the icon sets below; the Font Logos set (U+F300-U+F381) is removed.
The font's names and licence information are unchanged.
